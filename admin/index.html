إزاي أجيب التوكن؟ (مرة واحدة بس)
  1. افتح صفحة إنشاء التوكن وسجّل دخول.
  2. Token name: اكتب أي اسم (مثلًا: my-website). Expiration: اختار أطول مدة.
  3. Repository access ← Only select repositories ← اختار ريبو الموقع بس.
  4. Permissions ← Repository permissions ← Contents ← Read and write. (ولو حبيت: Pages ← Read-only عشان تشوف حالة النشر.)
  5. اضغط Generate token وانسخ التوكن والصقه هنا. هيتحفظ في متصفحك بس.
