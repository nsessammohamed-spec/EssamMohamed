خطوات تشغيل موقعك (مرة واحدة بس — حوالي 10 دقائق)
=====================================================

1) إنشاء المستودع على GitHub
   - ادخل على github.com واضغط New repository.
   - الاسم: لو سميته  اسم-حسابك.github.io  رابط موقعك هيبقى  https://اسم-حسابك.github.io
     ولو سميته أي اسم تاني (مثلًا my-website) الرابط هيبقى  https://اسم-حسابك.github.io/my-website/
   - لازم يكون Public (ده اللي بيخلي الاستضافة مجانية).

2) رفع الملفات
   - فك ضغط الملف، وادخل جوه فولدر my-website.
   - في صفحة الريبو اضغط  "uploading an existing file"  واسحب كل اللي جوه الفولدر
     (index.html و admin و assets و data و fonts وملف .nojekyll) واضغط Commit changes.
   - تنبيه: لو ملف .nojekyll مش ظاهر عندك (ملفات مخفية) متقلقش، الموقع هيشتغل برضه.

3) تفعيل الاستضافة (GitHub Pages)
   - من الريبو: Settings ← Pages ← Source: Deploy from a branch
     ← Branch: main  /(root) ← Save.
   - استنى دقيقة وافتح الرابط. موقعك شغال.

4) عمل التوكن (عشان لوحة التحكم تقدر تحفظ)
   - افتح:  https://github.com/settings/personal-access-tokens/new
   - Repository access: Only select repositories ← اختار ريبو الموقع.
   - Repository permissions: Contents ← Read and write.
     (واختياري: Pages ← Read-only عشان تشوف حالة النشر.)
   - Generate token وانسخه.

5) لوحة التحكم
   - افتح:  رابط-موقعك/admin/
   - الصق التوكن (واسم الريبو لو ماظهرش لوحده) واضغط دخول.
   - عدّل أي حاجة ← اضغط "معاينة" ← اضغط "نشر التعديلات". خلاص!
   - التعديل بيظهر على الموقع خلال دقيقة تقريبًا.

ملاحظات
   - كل المحتوى (النصوص، الأعمال، الألوان) جوه ملف واحد: data/site.js، واللوحة هي اللي بتعدّله.
   - كل نسخة قديمة محفوظة في GitHub (Account ← سجل التعديلات) وتقدر ترجع لأي منها.
   - التوكن محفوظ في متصفحك بس. لو دخلت من جهاز مش بتاعك اعمل "تسجيل خروج".
   - تقدر برضه تربط نفس الريبو بـ Cloudflare Pages أو Netlify (مجانًا)، واللوحة هتفضل شغالة.
